# ATM10 Crafting Planner

Crafting planner for Minecraft ATM10. Uses mod crafting recipes and creates a "Materials Needed" checklist starting from "Base Materials" and "How to craft" for user picked item.

## Features (planned)

- Total Materials Needed
- Progressive Crafting
- Crafting guide
- Live progress tracking
- Auto Import/Manual Import Recipes

## Tech

- Python 3.11.9 (or newer)
